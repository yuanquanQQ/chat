# 产品需求基线（v1.0）

## 1. 范围与约束

- 服务对象：单一公司，约 50 名用户、单一办公地点。
- 第一版客户端：Windows 10 Electron 客户端；暂不做手机版、浏览器独立版和桌面以外的客户端。
- 服务端：Windows 10，可运行 Docker Desktop，固定内网 IP；第一版仅内网访问，未来通过 VPN 扩展。
- 界面：中文；不做深色模式；暂不做手机适配。
- 品牌：公司名称、应用名称、Logo、主色使用独立配置文件，方便其他开发者复用。

## 2. 账号、组织和权限

用户自助注册，必须填写唯一自定义用户名、密码、真实姓名、头像和部门；新账号状态为“待审核”。管理员通过环境变量在首次启动时初始化，并审核通过、拒绝、禁用账号和手动重置密码。一个用户最多同时登录三台设备。

用户转部门需填写理由并提交申请，管理员审批后立即生效，系统保留申请和审核历史。群聊支持群主、群管理员、邀请、移除、修改群信息、公告、@成员、退出、解散和转让群主。

## 3. 聊天能力

支持单聊和群聊；消息类型包括文本、图片、视频文件、音频文件、普通文件和表情。支持引用、复制、搜索、单聊已读、群聊未读数量、历史分页和五分钟内撤回。撤回后显示“消息已撤回”，不物理删除文件。第一版不做实时音视频通话。

## 4. 文件能力

- 单个文件最大 10GB，默认永久保存，暂不按文件类型限制。
- 可执行文件可以传输和下载，但客户端不自动打开或执行。
- 图片、视频、音频、PDF 和文本提供只读预览；Office 第一版先下载，后续再增加预览。
- 小于 100MB 的文件默认服务器存储；大于等于 100MB 的文件默认保存在发送者客户端。
- 用户发送大文件时可以选择“长期保存到服务器”。客户端文件由发送者在线提供内网直连；发送者离线时显示不可用。
- 服务器保存全部文件元数据和权限信息；实际服务器文件进入 MinIO。

## 5. AI 中枢预留

第一版不实现 AI 主动任务、任务队列、多个会话访问或应用管理后台。只预留一个 AI 模块和指定会话绑定能力，未来可通过 HTTP 转发用户消息并展示返回结果。AI 不冒充员工，不读取未授权会话。

## 6. 运维与安全

Docker Compose 启动 Go 服务、PostgreSQL、Redis 和 MinIO。客户端只访问聊天服务统一入口 8080；数据库、Redis、MinIO 管理口不映射到宿主机。正式环境启用 HTTPS；备份、另一台电脑保存和一键恢复属于后续阶段。
